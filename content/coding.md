These are some projects I've done, usually to solidify my understanding of something (a new language, how something works in practice, etc). I'm also including projects I've done for school that I feel greatly improved my understanding of something. Since it's hard to gain an understanding of something you did't do yourself, nothing here was generated by LLMs, unless otherwise specified.

---

## C0 Compiler

A compiler for C0, a safe Turing-complete subset of C (essentially, C with slightly different allocation semantics and no pointer arithmetic), written in Rust. The compiler targeted both x86 and the LLVM IR. I also implemented various optimizations, my favorite of which were dead code elimination, loop-invariant code motion, and tail call conversion (tranforming functions to be tail-recursive using an accumulator).

## Systolic Array

In summer 2026, I interned at Annapurna Labs and was exposed to a lot of information about ML acceleration hardware. I decided to implement a basic weight-stationary systolic array in SystemVerilog to get a taste for what the hardware is actually doing. <a href="https://github.com/nmakur/SystolicArray">GitHub</a>.

## Dynamic Memory Manager

Essentially, implementing malloc() and free(). I had a lot of fun figuring out how to minimize the amount of metadata each block needs to hold and how to shrink the minimum block size from 32B to 16B. Something that I think was really nice about this is that I could see the parallels between dynamic (runtime) memory allocation and static (compile-time) memory allocation (the underlying ideas are the same, the main difference is what order the objects are allocated, and in what metadata is tracked).

## Interactive Shell

An interactive shell, supporting I/O redirection, foreground and background jobs, interupt signal forwarding, and cleanly reaping processes. I had a lot of fun thinking about signal handling logic and generally figuring out how to manage processes. It was also very useful with figuring out how to actually make use of the terminal as I was switching to linux.

## Config

I currently run debian. Right now, my config consists of two main parts: sway (my window manager), and vim. My sway config is fairly standard with a couple key remappings using ydotool. My vim config uses ALE and gutentags for a better development experience. The custom highlighting is largely LLM-written (in this day and age, learning vimscript instead of just using an LLM is probably not worth the time). <a href="https://github.com/nmakur/dotfiles">GitHub</a>.
